# Busco a alguien que… · Prep for the Cap. 16 presentation and IPA 2

A one-page, self-contained activity for Intermediate Spanish II (SPAN 2102). Students work in pairs, seated, with no notes.

**Live page:** `https://lisola628.github.io/busco-a-alguien-que/` (after enabling GitHub Pages)

## What is in the page
1. **Warm-up** · ¿qué palabra falta? (8 items, click to check)
2. **Round 1 · Tabú** · describe a Cap. 16 word without the forbidden words (timer and score)
3. **Round 2 · Busco a alguien que…** · six information-gap scenes (Card A / Card B)
4. **Round 3 · Una vida en cuatro frases** · a character plus three target words
5. **Homework** · one short recording prompt (60–90 seconds)

Directions are in English; all cards, examples and prompts are in Spanish.

## Use
Open `index.html` in any browser, or enable GitHub Pages (Settings → Pages → Deploy from branch → `main` / root). No installation. Scores reset on reload; the Print / PDF button works.
